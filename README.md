# Вектор

Telegram-бот для планирования дел и отслеживания личных целей.

Это первая версия проекта. Продолжение разработки и обновлённая реализация
находятся во второй версии репозитория.

Бот помогает управлять привычками, целями и событиями, а также отправляет
напоминания с учётом часового пояса пользователя.

## Возможности

- создание и отслеживание привычек;
- напоминания о привычках по выбранным дням и времени;
- создание целей и изменение их статуса;
- создание и редактирование событий;
- напоминания о событиях за день, час, 15 минут или выбранный срок;
- настройка часового пояса;
- просмотр статистики по привычкам и целям.

## Технологии

- Python;
- aiogram 3;
- SQLite;
- APScheduler;
- python-dotenv.

## Запуск

1. Создайте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

2. Активируйте его:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` в корне проекта:

   ```env
   API_TOKEN=токен_вашего_бота
   ```

5. Запустите бота:

   ```bash
   python main.py
   ```

Токен Telegram-бота можно получить через
[@BotFather](https://t.me/BotFather).

## Структура проекта

```text
vector-telegram/
├── handlers/          # обработчики разделов бота
├── main.py            # запуск приложения
├── database.py        # создание таблиц SQLite
├── db_utils.py        # запросы к базе данных
├── keyboards.py       # клавиатуры Telegram
├── scheduler.py       # отправка напоминаний
└── requirements.txt   # зависимости
```

База `vector.db` создаётся автоматически при первом запуске и не хранится
в репозитории.
